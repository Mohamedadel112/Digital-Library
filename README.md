## How to Run

### Option 1: Open Directly

- Simply double-click the `index.html` file in the project folder to open it in your web browser.

### Option 2: Using a Local Development Server (Recommended for Best Compatibility)

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Install a simple local server such as `http-server`:
   ```bash
   npm install -g http-server
   ```
3. Start the server from your project folder:
   ```bash
   http-server .
   ```
4. Open the provided local URL (usually `http://localhost:8080`) in your browser.
